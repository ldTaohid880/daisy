# 0007. Open source under MIT

- **Status:** Accepted
- **Date:** 2026-11-13
- **Supersedes in PLAN.md / UI_DESIGN_PLAN.md:** —

## Context

The owner chose an open-source licence.

## Decision

The code is MIT-licensed. Third-party dependencies must be MIT-compatible (MIT, BSD, Apache-2.0, ISC); CI checks licences.

## Consequences

Anyone may use and fork Daisy. Fonts and sample images in fixtures must be openly licensed too.
