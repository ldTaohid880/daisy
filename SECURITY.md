# Security policy

Daisy opens files from other people and shows their HTML, CSS and scripts, and it can let AI
apps on your computer edit projects. We take reports seriously.

**Report a vulnerability privately** through GitHub's "Report a vulnerability" (Security tab).
Please do not open a public issue. We aim to reply within 5 working days.

In scope: escaping the edit frame or preview frame, reading or writing files outside the project
the user chose, bypassing MCP access levels or approvals, update-channel tampering.

The design is in docs/architecture/SECURITY.md.
